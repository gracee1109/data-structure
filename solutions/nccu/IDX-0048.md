# IDX-0048｜Balanced String 最大拆分

政大 112 年｜計算機概論（科技組）｜問答題8｜上冊PDF頁碼：162。

涵蓋小題：問答題8。

## 題意摘要

將只含L、R且總數相等的字串分成最多個L／R各自相等的連續子字串。

## 解法與答案

一路維持L減R的balance；每次回到0立即切割。任何平衡子字串的終點都必須是累積balance回到0的位置，所以所有可切點全部切開最優。

RLRRLLRLRL→4；RLRRRLLRLL→2；修正為LLLRRR→1。

## 複雜度

- 時間：Θ(n)，單次掃描。
- 空間：O(1)。
