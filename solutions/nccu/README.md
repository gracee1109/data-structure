# 政大：34筆題解與C++17實作

依GitHub政大索引IDX-0025–IDX-0058，涵蓋111–115年全部**34筆大題索引、54個小題標記**。本批保留各索引ID與原卷小題對應。

PDF頁碼從封面起算。數列和樹形已檢視上冊第86、107、139、149、183、191頁原圖；圖檔與PDF留在本機，這裡只保存自行整理的文字與程式。

## 編譯與測試

需Python 3與支援C++17的g++；程式只依賴標準函式庫。從儲存庫根目錄執行：

```bash
g++ -std=c++17 -O2 solutions/nccu/IDX-0025.cpp -o /tmp/nccu-0025
/tmp/nccu-0025
python3 scripts/test_nccu.py
python3 scripts/test_nccu.py --sanitize
```

各.cpp以common.hpp共用完整演算法，故編譯時需保留同一資料夾中的header。測試將build產物放到臨時目錄；`--write-results`只在需要更新題目執行結果時使用。

已驗證34個題目入口與1個性質測試入口，全部以C++17編譯且將警告視為錯誤。AddressSanitizer／UndefinedBehaviorSanitizer亦通過；性質測試包含5,637組固定／隨機差分案例，核對AVL插刪、排序、最長路徑、LCS、Dijkstra、二元搜尋和字串拆分。

## 題目邊界

- 兩筆網路協定題IDX-0041／0043為跨組重複概念題；保留各自入口，示例只實作最短路徑，不宣稱實作完整網路協定。
- IDX-0033為一般圖最長簡單路徑，採指數時間精確DP；範例支援最多20個頂點。
- IDX-0032使用單節點高度1；IDX-0050依原題選項使用單節點高度0。
- Fibonacci和Pascal採uint64_t並檢查可表達範圍；複雜度以固定寬度整數模型分析。
- 排序／AVL中的逐步列印成本另列，避免把核心排序的O(n log n)說成整支追蹤程式的總時間。
- IDX-0048保留原題瑕疵說明，對不符合balanced前提的範例拒絕計算。
