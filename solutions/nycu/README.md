# 交大／陽明交大：10筆題解與C++17實作

依分校索引IDX-0059–IDX-0068，完成113–115年**全部10筆大題**。原索引標記18個小題，本批讀取完整大題後補齊4個未列標籤的小題，共**22個小題**。

每筆提供精簡題意、解法、時間／空間複雜度、可編譯C++17與執行結果。年度111、112未在這兩冊交大來源中收錄。

原題資料按PDF文字層與題圖核對。Prim第205頁圖、merge第207頁虛擬碼已直接檢視；114年路徑圖在PDF中以邊列表轉述。PDF與圖檔留在本機，程式與題解則自行整理。

## 編譯與測試

需Python 3與支援C++17的g++；程式只依賴標準函式庫。從儲存庫根目錄執行：

```bash
g++ -std=c++17 -O2 solutions/nycu/IDX-0059.cpp -o /tmp/nycu-0059
/tmp/nycu-0059
python3 scripts/test_nycu.py
python3 scripts/test_nycu.py --sanitize
```

每個.cpp是獨立題目入口，需保留同資料夾的common.hpp。Build產物寫到臨時目錄；`--write-results`用來重新保存各題的執行結果。

已驗證10個題目入口與1個性質測試入口，全部以C++17編譯且將警告視為錯誤。AddressSanitizer／UndefinedBehaviorSanitizer亦全部通過。性質測試共101,513組，包含最短路徑與窮舉簡單路徑比對、MST與邊子集枚舉比對、帶標記的穩定合併、全部65,536組8-bit運算輸入、雜湊滿表與負鍵，以及6頂點以下所有簡單無向圖的四環比對。

## 本批題目邊界

- IDX-0059涵蓋(a)–(e)，包括原索引省略的(b)。
- IDX-0060加入原索引省略的子集合計數(a)，不只處理遞迴式與雜湊。
- IDX-0061包含兩個root的Prim及邊集合比較；IDX-0063包含PDF第216頁的(c)。
- IDX-0065的frozenDijkstraForCounterexample專用於展示錯誤，一般dijkstra則拒絕負權重。
- IDX-0068說明O(n³)粗上界與提前終止時Θ(n²)緊界的差別；不沿用忽略return的成本結論。
- 計數與距離採有界整數，必要處檢查溢位；各題說明有效輸入範圍。
